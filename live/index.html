HOW LIVE FOOTBALL WILL WORK

The browser will never contain the private football API key. The frontend requests controlled data from our backend/serverless layer, which communicates with the football data provider.

01 FOOTBALL API Live fixtures and match events.
02 BACKEND Protects API credentials and handles requests.
03 LIVE ENGINE Normalizes and updates football data.
04 CHRONICLE Displays the live match centre.
